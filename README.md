# Execution Instructions
Execute in client/ or server/ maven javafx or maven spring-boot:
```
mvn javafx:run
mvn spring-boot:run
```
Compile server or client with:
```
mvn clean package
```
Note: The client's `pom.xml` targets Linux only (JavaFX Linux classifier).
